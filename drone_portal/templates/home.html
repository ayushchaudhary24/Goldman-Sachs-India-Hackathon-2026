Welcome to the Drone Routing Simulator

This is an open, browser-based sandbox for the Multi-Agent Drone Routing Simulator. Anyone can configure a city grid, a drone fleet and a set of delivery requests, then run the routing engine to obtain a validated Flight Manifest and watch it play out.

About the System

Urban logistics increasingly rely on autonomous drone fleets operating under complex, time-varying airspace regulations. No-Fly Zones (NFZs) activate and deactivate around scheduled events, convoys and construction works. This system assigns and routes a fleet of N drones from a central warehouse to complete M deliveries while respecting battery limits, payload capacities, delivery deadlines and dynamic airspace restrictions.

Key Capabilities

ModuleDescription
Fleet Assignment Distributes delivery requests across available drones by payload and deadline.
Temporal NFZ Avoidance Routes around or waits out circular and rectangular No-Fly Zones.
Energy & Charging Tracks battery consumption and schedules charging-station usage.
Flight Manifest Produces a validated, timestamped manifest for every drone.
Visualisation Animates drone routes, battery and payload on an HTML5 grid.

Get Started

Proceed to the Simulation Portal to enter inputs manually or upload a JSON configuration file, then execute the routing engine. For background information, see the Problem Overview and the Documentation.

What You Can Do Here
Build a scenario Set the map size, add drones, deliveries, charging stations and No-Fly Zones.
Import & export Upload or paste a JSON configuration, or generate one from the form.
Watch it run Animated route playback with battery, payload and a live simulation log.
Read the results Inspect the full Flight Manifest, performance summary and score.
