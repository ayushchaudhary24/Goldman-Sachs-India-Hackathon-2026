About

The Project

The Multi-Agent Drone Routing Simulator is an open, browser-based sandbox for autonomous urban logistics. It models a city as a two-dimensional grid and routes a fleet of delivery drones from a central warehouse under battery, payload, deadline and dynamic airspace constraints. It is a learning and experimentation tool, free for anyone to use.

Architecture

LayerTechnology
PresentationHTML, CSS, Vanilla JavaScript, HTML5 Canvas
ApplicationPython Flask
Computation EngineExisting Python routing solver (black box)

The presentation layer never performs routing of its own. It assembles the input, hands it to the engine, and faithfully replays the returned manifest for visualisation and statistics.

About This Project

This is an open, non-commercial project built for learning and experimentation. It is not affiliated with, endorsed by, or operated on behalf of any company, organisation or government authority. Any place names, scenarios or sample data are fictional and used only to illustrate the routing problem.

Using & Sharing

You are free to use the simulator, load your own scenarios and study the output. There is no sign-up and no support desk — the Documentation and Problem Overview pages explain everything you need to run a simulation and read the results.
